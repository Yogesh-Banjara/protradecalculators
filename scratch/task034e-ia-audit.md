## D. Orphan / Weakly Linked Pages Analysis

- **Orphan Assessment**: Zero true orphan pages exist. All 15 calculators are reachable via:
  1. Homepage interactive tools and suites grid.
  2. Header Trade Suites dropdown.
  3. Header Global Search (⌘K).
  4. Tools Directory `/tools`.
  5. Category hubs `/categories/[category]`.
  6. Sitemap `/sitemap.xml`.
- **Weak Link Risk**: The 3 planned empty suites (`landscaping`, `pallet-freight`, `woodworking`) generated hollow indexable pages with 0 tools. This presents thin-content crawl risk.

---

## E. Empty / Dead Suites Removal Plan

1. **`src/app/categories/[category]/page.tsx`**: Update `generateStaticParams()` to filter `TOOL_CATEGORIES.filter(c => c.status === "active")`. Non-active slugs return 404 via `notFound()`.
2. **`src/app/sitemap.ts`**: Generate sitemap entries only for active categories with real calculators.
3. **`src/components/layout/category-nav.tsx`**: Filter to active suites only.
4. **`src/app/page.tsx`**: Filter homepage suites grid to active suites only.
